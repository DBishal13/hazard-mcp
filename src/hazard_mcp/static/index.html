hazard-mcp

One MCP server that gives an AI agent the US hazard picture for any place: disaster declarations, weather alerts, earthquakes, wildfires, river gauges and live flood extent.

  • FEMA OpenFEMA
  • NWS alerts
  • USGS earthquakes
  • NASA EONET + FIRMS
  • NOAA NWPS gauges
  • NWM flood inundation

Try it

This is what the location_risk_summary tool returns, called through /api/summary. First lookups for a new place take a few seconds; repeats are cached.

Connect your agent

Add it as a remote MCP server (streamable HTTP, no auth):

In Claude, add it under Settings → Connectors → Add custom connector. Or run it locally over stdio: pip install git+https://github.com/DBishal13/hazard-mcp, then hazard-mcp.

Tools

location_risk_summaryGeocode a place and pull every source for the surrounding radius in one call.
render_hazard_mapTurn a summary into an interactive map (returns a link).
get_disaster_declarationsFEMA declarations by state and incident type.
get_nfip_claimsRedacted NFIP flood-insurance claims by state/county.
get_weather_alertsActive NWS alerts covering a point.
get_earthquakesUSGS earthquakes in a bounding box.
get_wildfire_events / get_active_firesNASA EONET wildfire events and FIRMS satellite hotspots.
get_river_gauges / get_flood_inundation_extentNOAA river gauges and live NWM flood-inundation polygons.
geocodePlace name to lat/lon (OpenStreetMap Nominatim).
